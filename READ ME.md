# Responsive Landing Page

A modern and responsive landing page built using HTML5, CSS3, and JavaScript.

## 🌐 Live Demo

[View Live Website](https://landing-page-moataz6.vercel.app/)

## 🛠️ Technologies Used

- HTML5
- CSS3
- BOOTS TRAP
- JavaScript

## ✨ Features

- Responsive design for mobile, tablet, and desktop.
- Mobile navigation menu.
- Scroll-reveal animations.
- Back-to-top button.
- Clean and modern user interface.
